Database entity–relationship reference

MYWMS is multi-tenant with database-per-tenant isolation. One root database (mywms) holds the tenant registry and every cross-company trade document; each tenant gets its own PostgreSQL database holding all operational data. Any reference that crosses that boundary is a soft foreign key — a plain column with no database constraint.
